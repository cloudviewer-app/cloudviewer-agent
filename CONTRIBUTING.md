# Contributing

Thanks for looking. This repository is maintained by one person and **does not
accept pull requests**, so that every line that ends up in a signed release is
written and reviewed by its maintainer. Pull requests will be closed without
review; this is not a judgement of the change.

What helps instead:

- **Bugs and ideas:** open an [issue](../../issues). Describe what you did,
  what you expected and what happened, with the agent version
  (`cloudviewer-agent --version`) and the OS.
- **Security issues:** never in a public issue. See [SECURITY.md](SECURITY.md):
  GitHub's private vulnerability reporting, or security@mitjamartini.com.
- **Questions about Cloud Viewer:** https://cloudviewer.app/support/

The code is open so that you can read exactly what runs on your server, and
fork it under its [license](LICENSE) if you want to change it.
